# SnapStudio — Phase 1

Bilingual (English / 中文), responsive Personal and Event photobooth starter.

## Run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Included
- Responsive minimalist homepage
- English/Chinese language toggle
- Personal and Event mode selection
- 3, 4, or 6 photo layout previews
- Four color themes
- Event name/date input (date is collected but will be rendered in Phase 2)
- Phase 2 placeholder confirmation

## Not yet implemented
Camera, countdown, capture, image export, event template storage, logo upload, real photos. These are planned for subsequent phases.
